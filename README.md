# Paradise Nursery

This is a React shopping app for browsing and buying plants online. Users can explore a curated collection of air-purifying, fragrant, insect-repelling, medicinal, and low-maintenance plants, add items to the cart, and manage quantities through Redux state.

## Project name
- e-plantShopping

## Features
- Responsive plant catalog page
- Redux-based cart state management
- Add, remove, and adjust item quantities
- Shopping cart summary and checkout flow
